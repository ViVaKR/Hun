### 🌿 Everforest 테마 맥락 강화 및 디테일 패치
- **다크 테마 코드 베이스 최적화:** 중복되던 심층 JSON Key 레벨(레벨 3~8) 스코프를 과감히 정리하여 에디터 렌더링 부하를 줄이고, Everforest 고유의 차분한 숲속 톤을 더욱 강조
