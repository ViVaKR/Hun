# 제어흐름

## 요약

- 어셈블리의 모든 조건문과 플래그 제어는 결국 **"0인가? 0이 아닌가?"** 라는 이 단 하나의 질문으로 귀결됩니다!

## ⚔️ CPU의 핵심 플래그 법칙 3줄  요약!

1. **`CMP A, B` (비교)** ➔ 사실 내부적으로 `A - B` (뺌 연산)를 해보고 **"결과가 0인가?"** 보는 ->것!
   * 같으면 ($A - B = 0$) ➔ **`eq` (Equal)**
   * 다르면 ($A - B \neq 0$) ➔ **`ne` (Not Equal)**


2. **`TST A, B` (비트 검사)** ➔ 사실 내부적으로 `A & B` (AND 연산)를 해보고 **"결과가 0인가?"** 보는 것!
   * 해당 비트가 1이면 ($A \& B \neq 0$) ➔ **`ne` (Not Equal)**
   * 해당 비트가 0이면 ($A \& B = 0$) ➔ **`eq` (Equal)**


3. **`CSET W0, NE`** ➔ 연산 결과가 **0이 아니면(`ne`) 1, 0이면(`eq`) 0**을 저장!

---

* 이 원리를 깨달으셨으니 이제 `b.ne`, `csel`, `cset`, `cbz`, `cbnz` 같은 AArch64의 온갖 조건문들이 술술 읽히실 겁니다.
