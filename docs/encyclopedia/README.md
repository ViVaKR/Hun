## 어셈블리 용어

### 🗺️ ARM64 어셈블리 핵심 용어 대조표

| 영어 용어 | 추천 한글어 | 의미 | 예시 |
| :--- | :--- | :--- | :--- |
| **Mnemonic**<br>(니모닉) | **명령어 이름** | CPU에게 시킬 동작의 영어 약어 | `ADD` (더하기), `SUB` (빼기), `MOV` (할당) |
| **Directive**<br>(디렉티브) | **어셈블러 지시어** | CPU가 아닌 **어셈블러(Clang)**에게 컴파일 방식을 지시하는 명령어 | `.global` (공개), `.align` (줄맞춤), `.text` (코드영역) |
| **Operand**<br>(오퍼랜드) | **피연산자** | 명령어 뒤에 따라붙는 대상(레지스터, 상수, 메모리 주소 등) | `ADD x0, x1, #10` 에서 `x0`, `x1`, `#10`이 피연산자이네. |
| **Register**<br>(레지스터) | **연산처 (혹은 기억방)** | CPU 내부에 있는 초고속 임시 기억 공간 | `x0` ~ `x30` (64비트 연산처), `w0` ~ `w30` (32비트 연산처) |
| **Label**<br>(레이블) | **이름표 (혹은 주소표)** | 특정 코드 위치나 데이터의 시작 주소에 붙이는 이름 | `_main:`, `인사말:` 처럼 끝에 콜론(`:`)이 붙네. |
| **Literal**<br>(리터럴) | **상수 (혹은 값)** | 코드에 직접 적어 넣은 고정된 숫자나 문자열 값 | `ADD x0, x0, #9` 에서 `#9`, `"Hello\0"` 등이 리터럴이네. |
| **Relocation Specifier**<br>(릴로케이션 수식어) | **주소 수식어** | 링커가 나중에 실제 주소값을 채워 넣을 수 있도록 돕는 표식 | `인사말@PAGE` (인사말 주소가 속한 4KB 페이지 주소) |
| **Macro**<br>(매크로) | **매크로 (혹은 문장뭉치)** | 반복되는 코드 패턴을 하나의 이름으로 묶어 재사용하는 틀 | `.macro CODE_SECTION` ... `.endmacro` |

---

### 💡 한글 코드 예시로 용어 짚어보기

```assembly
페이지주소찾기  연산처_0, 인사말@페이지
```
* **페이지주소찾기**: **니모닉 (명령어 이름)** -> 실제 CPU 명령어인 `adrp`를 뜻함.
* **연산처_0**: **피연산자 (오퍼랜드)** 이자 **레지스터** -> 실제 CPU의 `x0` 레지스터를 가리킴.
* **인사말@페이지**: **피연산자 (오퍼랜드)** 이자 **주소 수식어 (릴로케이션 수식어)** -> `인사말` 레이블(이름표)의 페이지 주소를 가리킴.

```assembly
코드영역
```
* **코드영역**: **어셈블러 지시어 (디렉티브)** -> 실제 어셈블러에게 "지금부터 진짜 CPU가 실행할 명령어들이 시작된다!" 하고 지시하는 `.text` 가 됨.

### 🏛️ 주유소 자동화 진지용 최선의 한글 매크로명 제안

| 기존 영문 매크로명 | 추천 한글 매크로명 | 의미 및 정렬 규칙 |
| :--- | :--- | :--- |
| **`CODE_SECTION`** | **`코드구역`** | 명령어 위치 (4바이트 정렬 고정) |
| **`DATA_SECTION`** | **`데이터구역`** | 일반 변수 공간 (8바이트 정렬 고정) |
| **`CSTRING_SECTION`** | **`글자구역`** 또는 **`글자상수구역`** | printf용 읽기전용 문자열 (8바이트 정렬) |
| **`CONST_DATA_SECTION`** | **`보호상수구역`** | 동적 링킹 후 읽기전용으로 보호되는 변수 구역 |
| **`CONST_SECTION`** | **`상수구역`** | 읽기전용 일반 상수/배열 구역 |
| **`LITERAL4_SECTION`** | **`실수사구역`** | float(4바이트 실수) 리터럴 구역 |
| **`LITERAL8_SECTION`** | **`실수팔구역`** | double(8바이트 실수) 리터럴 구역 |
| **`BSS_SECTION`** | **`빈변수구역`** | 0으로 자동 초기화되는 전역 변수 구역 |
| **`COMMON_SECTION`** | **`공용예약구역`** | 다중 선언 잠정 변수 예약 공간 |
| **`FUNC_START`** | **`문장시작`** | 일반적인 함수 프롤로그 시작 |
| **`FUNC_EXIT`** | **`문장끝`** | 일반적인 함수 에필로그 탈출 |
| **`FUNC_START_FULL`** | **`무장문장시작`** | 독서실(x19~x28) 풀 백업 프롤로그 |
| **`FUNC_EXIT_FULL`** | **`무장문장끝`** | 독서실 풀 복구 에필로그 |
| **`FUNC_EXIT_LIGHT`** | **`가벼운문장끝`** | 프레임 포인터만 닫는 초경량 탈출 |
