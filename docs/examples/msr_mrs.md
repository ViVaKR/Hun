# MSR / MRS 명령어 — 시스템 레지스터 접근

## Summary

**정의**: 범용 레지스터(X레지스터)와 **시스템 레지스터(System Register)** 사이에서 값을 주고받는 명령어 쌍. `MRS`는 시스템 레지스터 → 범용 레지스터(읽기), `MSR`은 범용 레지스터 → 시스템 레지스터(쓰기) 방향임.

---

## 기본 문법

```asm
MRS Xt, <system_register>      // 시스템 레지스터 값을 Xt로 읽어옴
MSR <system_register>, Xt      // Xt 값을 시스템 레지스터에 씀
```

**암기 팁**: `MRS`는 **R**ead(읽기)가 앞에, `MSR`은 뒤쪽이 **S**et에 가까운 쓰기 — 즉 R이 두 번째 글자면 "레지스터로 읽어온다(Read into register)", S가 두 번째 글자면 "레지스터 값을 (시스템에) 설정한다"고 구분하면 헷갈리지 않음.

---

## 시스템 레지스터란 무엇인가

**핵심 개념**: 일반 프로그램이 사용하는 X0~X30 같은 범용 레지스터와 달리, 시스템 레지스터는 **CPU/MMU/예외 처리 등의 동작 방식 자체를 제어하거나 그 상태를 보고**하는 특수 레지스터임. 이전 문서들에서 이미 여러 차례 등장했음:

| 시스템 레지스터 | 이전 등장 맥락 |
|---|---|
| `PAR_EL1` | `AT` 명령어 결과 확인용 (주소 변환 결과) |
| `SCTLR_EL1` | `ISB` 문서에서 MMU 활성화 설정 예시 |
| `VBAR_EL1` | `ISB` 문서에서 예외 벡터 테이블 설정 예시 |

즉, `MSR`/`MRS`는 이런 시스템 레지스터들을 실제로 읽고 쓰는 **범용 인터페이스 명령어**임.

---

## 접근 가능한 특권 레벨 — 레지스터마다 다름

**중요한 원칙**: 모든 시스템 레지스터가 EL0(일반 앱)에서 접근 가능한 것은 아님. 레지스터 이름의 접미사가 요구되는 특권 레벨을 나타냄.

| 접미사 | 의미 | 접근 가능 레벨 |
|---|---|---|
| `_EL0` | Exception Level 0 | 일반 앱에서도 접근 가능 |
| `_EL1` | Exception Level 1 | 커널만 접근 가능 |
| `_EL2` | Exception Level 2 | 하이퍼바이저만 접근 가능 |
| `_EL3` | Exception Level 3 | 시큐어 모니터만 접근 가능 |

**예시**:
```asm
mrs x0, sctlr_el1     // EL0에서 실행하면 → 예외(Illegal Instruction) 발생!
mrs x0, tpidr_el0       // EL0에서도 정상 접근 가능
```

**결과적 영향**: 일반 macOS 애플리케이션(EL0)에서 사용 가능한 `MRS`/`MSR` 대상은 `_EL0` 접미사가 붙은 소수의 레지스터, 그리고 NZCV(조건 플래그) 같은 특수 레지스터로 한정됨.

---

## 일반 애플리케이션(EL0)에서 실제로 쓰이는 사례

### 1. TPIDR_EL0 — 스레드 로컬 저장소(TLS) 포인터

**정의**: 각 스레드마다 고유한 데이터 영역(Thread-Local Storage)의 베이스 주소를 담는 레지스터.

```asm
mrs x0, tpidr_el0      // 현재 스레드의 TLS 베이스 주소 읽기
```

**실전 맥락**: macOS의 `pthread`, C++11의 `thread_local` 변수, Objective-C의 `errno` 처리 등 스레드별로 독립된 저장 공간이 필요한 모든 런타임 메커니즘의 근간이 되는 명령어. `libSystem` 내부에서 매우 빈번하게 사용됨.

---

### 2. NZCV — 조건 플래그 레지스터 직접 접근

**이전 문서 연결**: `CMP`, `ANDS` 등으로 자동 설정되는 N/Z/C/V 플래그를 범용 레지스터로 통째로 읽거나 쓸 때 사용.

```asm
mrs x0, nzcv       // 현재 조건 플래그 상태를 x0에 읽어옴
msr nzcv, x0         // x0 값으로 조건 플래그 상태를 강제 설정
```

**용도**: 함수 호출 전후로 플래그 상태를 저장·복원해야 하는 경우, 또는 예외 처리 핸들러에서 이전 실행 컨텍스트의 플래그를 복원할 때 사용됨.

---

### 3. FPCR / FPSR — 부동소수점 제어/상태 레지스터

```asm
mrs x0, fpcr       // 부동소수점 제어 레지스터 (반올림 모드 등) 읽기
mrs x0, fpsr        // 부동소수점 상태 레지스터 (오버플로우, NaN 발생 여부 등) 읽기
msr fpcr, x0        // 반올림 모드 등 부동소수점 연산 제어 설정
```

**실전 맥락**: 이전 `FMLA`/`FMLS` 문서와 연결됨. 부동소수점 연산의 반올림 방식(round-to-nearest, round-toward-zero 등)을 명시적으로 제어하거나, 연산 중 예외(0으로 나누기, 오버플로우 등) 발생 여부를 확인할 때 EL0에서도 접근 가능함.

---

### 4. CNTVCT_EL0 — 타이머/사이클 카운터

```asm
mrs x0, cntvct_el0    // 가상 카운터(타이머) 값 읽기, 고정밀 시간 측정용
```

**실전 맥락**: 성능 프로파일링, `mach_absolute_time()` 같은 고정밀 시간 측정 API의 내부 구현에서 활용됨.

---

## 커널 전용 사례 — EL1 이상 (참고용, 직접 사용 불가)

**이전 문서들에서 이미 다룬 시스템 레지스터 조작 재확인**:

```asm
// ISB 문서에서 다룬 예시
msr sctlr_el1, x0     // MMU/캐시 활성화 등 시스템 제어
isb

// 예외 벡터 설정
msr vbar_el1, x0      // 예외 벡터 테이블 주소 설정
isb

// AT 문서에서 다룬 주소 변환 결과 확인
at s1e1r, x0
mrs x1, par_el1         // 변환 결과(PAR_EL1) 읽기
```

**공통점**: 이런 EL1 레지스터들은 커널 코드에서만 등장하며, 대부분 직후에 `ISB`가 뒤따르는 패턴을 보임 — 이전 `ISB` 문서에서 설명한 "시스템 레지스터 변경 후 파이프라인 재동기화 필요성"이 바로 이 맥락임.

---

## MRS/MSR과 짝을 이루는 배리어 명령어 — 재확인

**중요한 원칙 재확인**: 시스템 레지스터를 `MSR`로 변경한 직후, 그 효과에 의존하는 코드를 실행하려면 `ISB`가 필요할 수 있음(레지스터 종류에 따라 다름). 이는 이전 `ISB` 문서의 핵심 내용과 정확히 연결됨.

```asm
msr sctlr_el1, x0
isb                    // 변경사항이 확실히 반영된 후 이후 명령어 페치되도록 보장
```

---

## PSTATE 관련 특수 MSR 형태 — 즉치값 버전

**특이 사항**: 일부 PSTATE(Process State) 필드는 레지스터가 아니라 **즉치값(immediate)** 으로 직접 설정 가능한 특수 `MSR` 형태가 존재함.

```asm
MSR DAIFSet, #imm     // 인터럽트 마스크 비트 설정 (Debug, SError, IRQ, FIQ)
MSR DAIFClr, #imm     // 인터럽트 마스크 비트 해제
MSR SPSel, #imm         // 어느 스택 포인터(SP_EL0 vs SP_ELx)를 쓸지 선택
```

**예시**:
```asm
msr daifset, #0xF     // 모든 인터럽트/예외 마스킹 (인터럽트 비활성화)
msr daifclr, #0xF     // 마스킹 해제 (인터럽트 다시 활성화)
```

**용도**: 커널의 임계 구역(critical section) 진입 시 인터럽트를 잠시 막아야 하는 상황에서 사용됨 — 일반 앱에서는 접근 불가.

---

## 종합 정리표

| 레지스터 | 접근 레벨 | 용도 | 실전 활용 예 |
|---|---|---|---|
| `TPIDR_EL0` | EL0 | 스레드 로컬 저장소 포인터 | pthread, TLS 변수 |
| `NZCV` | EL0 | 조건 플래그 직접 접근 | 예외 핸들러의 플래그 저장/복원 |
| `FPCR`/`FPSR` | EL0 | 부동소수점 제어/상태 | 반올림 모드, FP 예외 확인 |
| `CNTVCT_EL0` | EL0 | 타이머 카운터 | 고정밀 시간 측정 |
| `SCTLR_EL1` | EL1 | MMU/캐시 제어 | 커널 초기화 |
| `VBAR_EL1` | EL1 | 예외 벡터 테이블 주소 | 커널 예외 처리 설정 |
| `PAR_EL1` | EL1 | 주소 변환 결과 | `AT` 명령어와 짝 |
| `DAIFSet`/`DAIFClr` | EL1 | 인터럽트 마스킹 | 커널 임계 구역 |

---

## 최종 결론

`MRS`/`MSR`은 CPU의 "설정 다이얼과 계기판"에 접근하는 창구 역할을 하는 명령어 쌍임. 대부분의 시스템 레지스터는 `_EL1` 이상 접미사가 붙어 커널 전용이지만, `TPIDR_EL0`(스레드 로컬 저장소), `NZCV`(플래그), `FPCR`/`FPSR`(부동소수점 제어) 같은 `_EL0` 레지스터들은 일반 macOS 애플리케이션에서도 실제로 사용되며, 특히 `libSystem`의 pthread·TLS 구현이나 부동소수점 라이브러리 내부에서 자연스럽게 관찰되는 명령어임. 지금까지 다룬 `AT`, `ISB`, `WFE` 문서와 함께 보면, macOS 어셈블리에서 시스템 레벨 명령어들이 서로 어떻게 유기적으로 얽혀 동작하는지가 한눈에 정리될 것임.
